# Green Line Tokyo

목적지를 넣으면, 도쿄 경시청 시간제한주차구간(파킹 미터·티켓) 중 **일요일·공휴일에 미터가 쉬는 녹색 구간**을 가까운 순으로 보여 주는 정적 웹페이지입니다. 내 위치 → 주차 구간(운전) → 목적지(도보) 경로와 거리를 지도에 그리고, 구글맵 길안내·도보 경로·거리뷰(표지 확인)로 바로 이어집니다.

- 날짜별 판정: 일·공휴일 → 녹색 구간 / 토요일 → 「土・日曜、休日を除く」 구간 / 1월 1~3일 → 전 구간 / 평일 → 없음
- 공휴일: 일본 「国民の祝日に関する法律」 규칙(대체휴일·국민의 휴일 포함)을 코드로 계산
- 주의: 미터가 쉬는 날 주차 가능 여부는 현장 표지가 정합니다. 「駐車禁止」 표지가 함께 있으면 그 시간엔 주차할 수 없습니다(경시청 FAQ).

## 외부 서비스(브라우저에서 직접 호출)
- 지도: 국토지리원 地理院タイル(淡色地図)
- 경로: FOSSGIS OSRM(routing.openstreetmap.de, car/foot), 데이터 © OpenStreetMap 기여자
- 장소 검색: 내장 목록(Wikidata) → 없으면 국토지리원 주소 검색·Nominatim(검색 버튼을 누를 때만)

## 파일
- `index.html` — 페이지 전체(빌드 없음)
- `zones.json` — 경시청 [時間制限駐車区間 案内地図](https://parking-meter.jp/) 공개 GeoJSON을 줄인 것(752개 구간, 2026-11-23 받음)
- `places.json` — 역·명소 이름과 위치, [Wikidata](https://www.wikidata.org/)(CC0)

## 데이터 갱신
`https://parking-meter.jp/parkingmeter.geojson`을 다시 받아 `zones.json`을 만들면 됩니다. 필드: `r`(0=일·공휴일도 작동, 1=日曜・休日を除く, 2=土・日曜、休日を除く), `h` 운영시간, `m` 제한시간(분), `f` 수수료(엔), `t` 1=미터/0=티켓, `c` 일반차 가능, `g` 화물차 전용 칸 있음, `l` 좌표.
